Production main не изменяется. Тестовое приложение имеет независимые данные и устанавливается рядом с оригинальным; версия 36 предназначена для обновления test3 (35).

## Тихое расписание

Один полноценный запуск — новый экземпляр главной Activity после закрытия/завершения предыдущей задачи либо новый процесс. Возврат в живую задачу, `onResume`, настройки, системные разрешения и пересоздание Activity при смене конфигурации не являются новой проверкой. Компонент ScheduleUpdateChecker сохраняется при пересоздании конфигурации. После завершения Activity новый запуск снова проверяет manifest, в том числе после ошибки предыдущей попытки. Никакого недельного ограничения нет.

Локальный экран создаётся прежде, чем ставится фоновая задача. Проверка сети, HTTPS-загрузка manifest, сравнение версий, загрузка изменившихся годов, прежняя валидация и атомарное сохранение выполняются вне UI-потока. Работающие данные остаются при offline, timeout, DNS/HTTP error и повреждении файла. Пользовательских экранов, состояний загрузки, ошибок, уведомлений или кнопок обновления нет. На дату без данных остаётся нейтральное сообщение об отсутствии расписания.

Источник: https://emilzhianshin-dot.github.io/namaz-schedules/manifest.json.
Встроенные 153 дня для каждого города за 1 августа — 31 декабря 2026 сохранены точно. Реальные данные будущих лет не добавлялись. Фикстуры 2027–2028 в тестах синтетические и не попадают в APK. Новые годы подхватываются по manifest без изменения APK; исправление требует повышения version и пересчёта bytes/SHA-256.

## Остальные изменения

- Уведомления при новой установке выключены. Явная сохранённая настройка пользователя сохраняется; включение работает прежним способом.
- Джума без известного Асра не скрывается уже в полночь. Время окончания не придумывается: при неизвестном Асре пятничная метка остаётся до смены дня; при известном — исчезает ровно в Аср.
- Исправлены подтверждённые случаи обрезания крупного текста. Цвета, порядок экранов и карточек сохранены. На крупном шрифте допускается прокрутка.
- Добавлены невидимые подписи для средств доступности.
- Кибла, Hijri, подтверждённые религиозные даты, формат уведомлений и подпись не заменялись.

## Проверка и сборка

JDK 17, Android SDK 35, Build Tools 35.0.0:

```sh
python3 scripts/preflight.py
bash gradlew --no-daemon clean :app:testReleaseUnitTest :app:lintRelease :app:assembleRelease
bash scripts/verify-apk.sh
```

CI ограничен тестовыми ветками, использует Gradle Wrapper и проверяет идентификатор, версию, сертификат, INTERNET и запрет cleartext HTTP. Отчёты тестов и APK являются отдельными артефактами. Никакой публикации в магазины нет.

Подпись: текущий ключ сохранён для совместимости. Его прежнее размещение в публичном репозитории — нерешённая security-проблема. План: согласовать доступ владельца к защищённым GitHub Secrets, отдельно сохранить резервную копию, передавать keystore и пароли в CI только через secrets, не хранить их в новых исходниках. Удаление файла из текущей версии не отменяет прежнее раскрытие; замену сертификата и любые действия с историей или опубликованным приложением согласовывать отдельно.

Подробные результаты и ограничения проверки приведены в отчёте этой доработки. Роботизированная проверка UI и Android-компонентов не заменяет установку на физическое устройство, TalkBack, аппаратный компас и проверку доставки уведомлений при энергосбережении.
