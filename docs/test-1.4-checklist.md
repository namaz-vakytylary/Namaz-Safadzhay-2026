# Namaz Vakytylary 1.4-test3 — проверка на телефоне

Только пакет ru.namaz.safadzhay.test, versionCode 39. Стабильную 1.3 не удалять.
Локальный debug APK не заменяет подписанный APK из RuStore. Если уже установлен
TEST с другим сертификатом, не удаляйте его ради установки: удаление уничтожит
его кеш. Для обновления такого TEST нужен APK с прежним TEST-сертификатом из CI.

1. Чистый TEST без сети: времени намазов нет, есть понятное сообщение и повтор.
2. Включить сеть, повторить загрузку, проверить оба города; выключить сеть,
   полностью закрыть приложение, снова открыть — сохранённые времена те же.
3. По возможности использовать прежний подписанный TEST с загруженным кешем;
   установить новый TEST поверх без очистки данных, проверить оба города офлайн.
   Это не заменяет проверку реального обновления production 1.3→1.4 перед релизом.
4. Автоопределение при новом запуске, затем ручной выбор во время поиска.
   Запоздалый ответ не меняет город. Поворот/пересоздание сохраняет ручной выбор;
   завершение процесса разрешает новое определение. Проверить coarse/fine,
   отказ/отзыв разрешения, отключённую геолокацию, молчащий сетевой провайдер.
5. Включить уведомления и нужные разрешения, проверить выбранный город, звук,
   татарские названия, разные интервалы и отключение отдельных намазов.
   Проверить перезагрузку, смену часового пояса/времени, смену города и настроек.
   Устаревшие напоминания не должны появляться повторно.
6. Проверить System/Light/Dark, крупный шрифт, TalkBack, Киблу, 12:00 и компактный
   экран. Рамадан проверять через существующие TEST-превью; реальные религиозные
   даты берутся из проверенных данных, даты 2027 не подставляются.
7. Окно расписаний: этапы проверки/загрузки/валидации, реальные проценты,
   отмена кнопкой «Назад», повтор после сети. При ошибке предыдущий кеш остаётся.
8. Окно приложения: существующее TEST-превью проверяет оформление состояний,
   логотип и кнопки; оно не скачивает и не устанавливает обновление.
   Реальный цикл RuStore требует распознаваемого магазином пакета/сертификата,
   авторизованного RuStore и доступной новой версии. Отдельно проверить отказ,
   продолжение работы, возврат после загрузки, установку и частоту не чаще 24 ч.

На Samsung/Xiaomi/Honor отдельно проверить сон/Doze, режим энергосбережения,
ограничения автозапуска и запрет уведомлений/канала. После force-stop Android
может блокировать уведомления до ручного открытия приложения. Гарантированная
доставка при системных ограничениях не обещается.

## Сборка и границы

`python3 scripts/repository-security.py`
`python3 scripts/preflight.py`
`python3 -m unittest discover -s scripts -p 'test_*.py'`
`bash gradlew :app:testDebugUnitTest :app:testReleaseUnitTest :app:lintDebug :app:lintRelease :app:assembleDebug`

Подписанный TEST: workflow Build Namaz Vakytylary TEST offline schedules
запускается вручную либо при изменении приложения, скриптов или сборочной
конфигурации в TEST-ветке
на разрешённой TEST-ветке, с уже существующими секретами/сертификатом.
assembleRelease требует обе группы тестов, lint и проверку сертификата.
Main, серверные данные и опубликованный APK не меняются.

R8 оставлен выключенным. В коде используется явный JSON-парсинг, но RuStore/Tink
содержат собственные зависимости и consumer rules. Для включения нужен отдельный
TEST-прогон minified APK: API 23/28/31/33/35, кеш 1.3, все приёмники и отложенные
события, RuStore, темы/превью/Кибла. Сравнить размер, mapping и производительность
на телефоне. Текущий замер 28,5 мс — медиана чтения кеша на JVM сборочного хоста,
а не измерение запуска или расхода батареи Android-смартфона.
