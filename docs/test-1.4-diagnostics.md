# 1.4-test2: шесть TEST-проверок

Рабочая ветка: `test/1.2-test3-security`. Пакет `ru.namaz.safadzhay.test`,
versionCode 38. Main и серверные данные не изменяются. APK устанавливать поверх
прежнего подписанного TEST без очистки данных. Production 1.3 не удалять.

## Что проверить

1. Настройки → **Данные расписаний**. Сверить загруженные годы, версии и города,
   диапазон дат, наличие данных на реальную сегодняшнюю дату выбранного города.
   Время — существующая отметка последней успешной проверки обновлений;
   если старый кеш не содержит отметки, отображается отсутствие записанного времени.
   Состояние относится к последнему чтению/успешному сохранению файла, а не
   к непрерывной проверке диска. Открытие не обращается к GitHub.
2. Первый запуск без сети/кеша: нет времён, есть **Повторить**. После загрузки
   обоих городов выключить сеть, закрыть TEST и открыть заново. Проверить оба
   города; кнопка повтора при доступных данных скрыта, окна загрузки нет.
   Ошибка/отмена загрузки не должна уничтожать предыдущую проверенную копию.
3. Настройки → **Диагностика · TEST** → **Проверка уведомлений · TEST**.
   Сверить город, дату, время намаза и отдельное время напоминания по МСК,
   разрешения Android, канал выбранного звука, точный/неточный способ.
   Нажать **Обновить сведения** — количество и время будильников не меняются.
   Это журнал успешных вызовов AlarmManager в текущем процессе, а не полный
   системный список и не подтверждение доставки. PendingIntent тоже не доказывает
   сохранность будильника после вмешательства Android/OEM. При отсутствии
   наблюдений экран прямо сообщает об этом; он не восстанавливает будильники.
4. **Геолокация · TEST**: автоматический город, сеть/GPS и время принятого
   результата. После ручного выбора — ручной режим и активная защита. Запоздалый
   ответ не меняет город или диагностический результат. При пересоздании Activity
   в том же процессе последний результат сохраняется; после нового процесса
   неизвестный источник не угадывается. Координат и истории перемещений нет.
5. Существующая **Проверка Рамадана**: обычный день, до окончания сухура,
   ровно Фаджр (окончание сухура), до ифтара, наступивший ифтар. Времена границ
   берутся из проверенного расписания выбранного города, без изменения его значений.
   Проверить светлую/тёмную темы, экран 320dp и увеличенный шрифт. Тестовые часы
   меняют только UI; обновления данных и уведомления обслуживаются по реальной дате.
6. **Диагностика · TEST**: реальная версия/пакет, кеш, единственный источник
   GitHub, разрешения и переходы. Экран не отправляет отчёты и не запрашивает
   разрешения. Окно обновления самого приложения не дорабатывалось.

## Изоляция и ограничения

Диагностические реализации и чтение сведений находятся в `src/debug/java`.
Текущий подписанный TEST release использует этот source set только при точном
TEST applicationId, как существующее превью Рамадана. В `src/release/java`
оставлены заглушки без экранов и без сбора TEST-метаданных.

Кеш `filesDir/downloaded-schedules.json` и его schemaVersion 1 не менялись.
Автотесты читают формат 1.3 офлайн без перезаписи и потери обоих городов.
Отдельный TEST package не доказывает реальную установочную миграцию production
1.3→1.4: она требует разрешённого production APK с прежней подписью и телефона.

На устройствах проверить Doze, перезагрузку, отзыв разрешений, выключенный канал,
ограничения Samsung/Xiaomi/Honor. Доставка при системных ограничениях не обещается.
Данные 2027 не создаются. Ed25519 остаётся подготовленным, но не обязательным.

Официальные API: [AlarmManager](https://developer.android.com/reference/android/app/AlarmManager),
[PendingIntent.FLAG_NO_CREATE](https://developer.android.com/reference/android/app/PendingIntent#FLAG_NO_CREATE).
